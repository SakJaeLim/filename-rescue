## 제목

## 부제

`코로나.pdf`처럼 자모가 분리된 파일명을 Windows에서 정상 한글 이름으로 되돌리는 작은 도구를 만들었습니다.

---

파일을 받았는데 이름이 이상하게 보인 적이 있었습니다.

원래는 `코로나19로.pdf`처럼 보여야 하는데, 실제로는 `코로나19로.pdf`처럼 자음과 모음이 분리된 상태로 보이는 경우입니다. 처음에는 단순한 인코딩 깨짐처럼 느껴지지만, 실제로는 파일명이 분해형 유니코드로 저장된 경우가 많습니다.

이 문제는 생각보다 자주 생깁니다.

- 맥에서 만든 파일을 윈도우에서 열 때
- OneDrive나 메신저로 받은 파일일 때
- 압축 파일을 풀면서 이름이 그대로 넘어왔을 때
- 문서가 많은 폴더에서 검색과 정리가 꼬일 때

이걸 매번 손으로 고치는 건 생각보다 피곤합니다. 파일이 몇 개만 돼도 귀찮고, 논문 자료나 제안서처럼 문서가 많아지면 거의 반복 노동에 가깝습니다.

그래서 이 문제만 빠르게 해결하는 작은 Windows 도구를 만들었습니다. 이름은 `파일명구조대`입니다.

## 파일명구조대가 하는 일

파일명구조대는 깨진 한글 파일명을 찾아서 정상 한글 이름으로 복구합니다.

예를 들어:

- `코로나19로.pdf` -> `코로나19로.pdf`
- `가상자산 시계열.pdf` -> `가상자산 시계열.pdf`

핵심 기능은 아래와 같습니다.

- 깨진 한글 파일명 자동 탐지
- 변경될 이름 미리보기
- 파일 여러 개 드래그앤드롭
- 폴더 단위 일괄 처리
- 충돌 이름 자동 감지
- 실행 로그 저장

즉, “파일명을 안전하게 일괄 정상화하는 도구”라고 생각하시면 됩니다.

## 사용 방법

1. 프로그램을 실행합니다.
2. 폴더를 고르거나 파일 여러 개를 창에 드래그해서 놓습니다.
3. 바뀔 이름 목록을 확인합니다.
4. `이름 변경 실행` 버튼을 누릅니다.

설치 과정 없이 바로 쓸 수 있고, 파일 내용은 읽지 않고 이름만 바꾸도록 만들었습니다.

## 왜 GitHub에 올렸나

이런 유틸리티는 기능만큼 신뢰가 중요하다고 생각했습니다.

- 파일 내용을 읽는지
- 이상한 수집을 하는지
- 광고가 붙는지
- 업데이트와 개선 요청이 가능한지

그래서 소스를 공개하고, 누구나 검토하고 피드백할 수 있게 GitHub에 올렸습니다.
